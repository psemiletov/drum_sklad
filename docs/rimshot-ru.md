# Документация генератора римшота (Rimshot)

Генератор `rimshot` — это специализированный модуль перкуссионного синтеза в Drumlabooh для создания четких звуков удара по ободу барабана (Rimshot / Cross-stick). Алгоритм объединяет высокочастотный резонансный корпус с отфильтрованным шумовым щелчком атаки, огибающей и опциональной сатурацией.

Формат вызова:
```text
rimshot(freq=val1, decay=val2, click=val3, tone=val4, drive=val5)
```

## Таблица параметров

| Параметр | Тип | По умолчанию | Диапазон | Описание |
| :--- | :--- | :--- | :--- | :--- |
| **`freq`** | `float` | `440.0` | `150.0` — `1200.0` | Базовая фундаментальная частота резонанса обода/корпуса (в Гц). |
| **`decay`** | `float` | `0.12` | `0.02` — `1.0` | Общая длительность и коэффициент затухания хвоста (в секундах). |
| **`click`** | `float` | `0.7` | `0.0` — `2.0` | Интенсивность шумового щелчка удара палочки по ободу. |
| **`tone`** | `float` | `2500.0` | `800.0` — `8000.0` | Частота среза фильтра НЧ, формирующего тембр щелчка (в Гц). |
| **`drive`** | `float` | `1.4` | `0.5` — `5.0` | Коэффициент сатурации/перегруза через функцию `std::tanh`. |

---

## Архитектура и особенности звукообразования

1. **Резонансный корпус с питч-огибающей:**
   Тональная составляющая моделирует резкий отклик обода с помощью синусоидального осциллятора с быстрым экспоненциальным падением частоты от повышенного значения к базовой `freq`:
   $$\text{current\_freq} = \text{freq} + \text{freq} \cdot 0.8 \cdot \exp(-t \cdot 80.0)$$
   Амплитуда затухает по экспоненте в зависимости от параметра `decay`.

2. **Шумовой щелчок атаки:**
   Детерминированный генератор псевдослучайных чисел Xorshift (`rim_noise_state = 54321`) создает шум, который фильтруется однополюсным RC-фильтром НЧ по параметру `tone`. В первые $3\text{ мс}$ линейный спад формирует хлесткий удар палочки, переходящий в короткий затухающий хвост.

3. **Сатурация и финальная обработка:**
   Смешанный сигнал тела и щелчка при $\text{drive} > 1.0$ проходит через мягкий ограничитель `std::tanh`, придающий характерный плотный хруст. В конце буфера применяется сглаживание кроссфейда на $3\text{ мс}$ (`apply_buffer_fadeout`).
