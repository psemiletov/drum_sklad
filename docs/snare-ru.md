# Документация генератора малого барабана (Snare)

Генератор `snare` — это универсальный модуль синтеза в Drumlabooh для создания акустических и электронных звуков малого барабана. Алгоритм объединяет тональную составляющую корпуса (тела) с настраиваемым падением частоты и шумовой компонент с фильтрацией, имитирующий пружины барабана.

Формат вызова:
```text
snare(f0=val1, f1=val2, decay=val3, noise=val4, n_decay=val5)
```

## Таблица параметров

| Параметр | Тип | По умолчанию | Диапазон | Описание |
| :--- | :--- | :--- | :--- | :--- |
| **`f0`** | `float` | `200.0` | `80.0` — `500.0` | Начальная частота атаки тональной составляющей корпуса (в Гц). |
| **`f1`** | `float` | `110.0` | `50.0` — `300.0` | Конечная фундаментальная частота тональной составляющей (в Гц). |
| **`decay`** | `float` | `0.18` | `0.05` — `1.0` | Время спада огибающей тонального тела барабана (в секундах). |
| **`noise`** | `float` | `0.6` | `0.0` — `2.0` | Относительный уровень микса шумовой составляющей пружин. |
| **`n_decay`** | `float` | `0.12` | `0.02` — `1.0` | Время спада огибающей шумового компонента (в секундах). |

---

## Архитектура и особенности звукообразования

1. **Синтез тела барабана и модуляция высоты:**
   Тональная часть моделирует резонанс корпуса синусоидальным осциллятором с быстрым экспоненциальным падением частоты. Частота изменяется от `f0` к `f1` по формуле:
   $$\text{freq} = f_1 + (f_0 - f_1) \cdot \exp(-t \cdot 45.0)$$
   Амплитуда тела затухает по экспоненциальному закону, зависящему от параметра `decay`.

2. **Шум пружин и фильтрация:**
   Компонент пружин использует детерминированный генератор псевдослучайных чисел Xorshift (`snare_noise_state = 12345`). Сырой шум обрабатывается однополюсным RC-фильтром нижних частот с фиксированной частотой среза $2500\text{ Hz}$, придавая характерный шелест. В первые $1.5\text{ мс}$ огибающая шума плавно нарастает во избежание щелчков при старте.

3. **Сатурация и финишная обработка:**
   Смешанный сигнал корпуса и шума проходит через мягкое ограничение (soft clipping) с помощью функции `std::tanh` с коэффициентом перегрузки $1.3$. В конце буфера выполняется сглаживание финального кроссфейда через функцию `apply_buffer_fadeout`.
