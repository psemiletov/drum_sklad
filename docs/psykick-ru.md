# Документация генератора Psytrance Kick (Psykick)

Генератор `render_psykick` — это специализированный движок синтеза электронной перкуссии в Drumlabooh, разработанный специально для Psytrance, Гоа и быстрых гипнотических жанров электронной музыки. Он моделирует фирменный «псай-лазерный» панч за счет комбинации экспоненциальной огибающей падения питча, фазовой модуляции (FM) для панча, рекурсивного затухания амплитуды, агрессивной стадии вейшейпера/клиппинга для плотности, высокочастотного шумового транзиента с HPF и чистого сглаживания буфера на хвосте.

Формат вызова:
`psykick(f0=val1, f1=val2, decay=val3, click=val4, drive=val5, curve=val6, fm=val7, click_hp=val8)`

## Таблица параметров

| Параметр | Тип | По умолчанию | Диапазон | Описание |
| :--- | :--- | :--- | :--- | :--- |
| **`f0`** | `float` | `240.0` | `80.0` — `500.0` | Начальная стартовая частота огибающей падения питча (в Гц). |
| **`f1`** | `float` | `38.0` | `20.0` — `80.0` | Конечная базовая саб-частота тела бочки (в Гц). |
| **`decay`** | `float` | `0.22` | `0.05` — `1.0` | Общий фактор длительности огибающей, определяющий длину хвоста (в секундах). |
| **`click`** | `float` | `0.25` | `0.0` — `1.0` | Уровень амплитуды транзиентного щелчка на базе отфильтрованного шума. |
| **`drive`** | `float` | `0.5` | `0.0` — `1.0` | Интенсивность дисторшна вейшейпера и клиппинга для гармонической плотности и кача. |
| **`curve`** | `float` | `35.0` | `5.0` — `100.0` | Крутизна питч-огибающей, определяющая скорость падения частоты. |
| **`fm`** | `float` | `0.3` | `0.0` — `2.0` | Глубина фазовой модуляции (FM), придающая характерный псай-лазерный оттенок атаке. |
| **`click_hp`** | `float` | `3000.0` | `500.0` — `8000.0` | Частота среза фильтра высоких частот для формирования щелчка (в Гц). |

## Архитектура и звуковые особенности

1. **Крутое падение питча и фазовая модуляция (FM):**
   - Мгновенная частота модулируется экспоненциальной кривой затухания, управляемой параметром `curve`:
     $$\text{freq} = f_1 + (f_0 - f_1) \cdot \exp(-t \cdot \text{curve})$$
   - Накопление фазы интегрирует специальный FM-модулятор (`fm_mod`) в начале удара для создания фирменного лазерного щелчка:
     $$\text{phase} += 2.0 \cdot \pi \cdot (\text{freq} + \text{fm\_mod}) \cdot \text{dt}$$

2. **Рекурсивное затухание амплитуды и дисторшн (Waveshaper):**
   - Амплитуда формируется рекурсивно через коэффициент затухания (`env *= env_factor`) для максимальной производительности.
   - Сигнал с перегрузом проходит через вейшейпер, объединяющий пре-гейн ($1.0 + \text{drive} \cdot 6.0$), жесткое ограничение и линейную интерполяцию через `juce::jmap`.

3. **Отфильтрованный щелчок атаки и сглаживание:**
   - Шум Xorshift, генерируемый в первые $4\text{ мс}$ ($t < 0.004\text{ с}$), проходит через 1-полюсный фильтр высоких частот (`hp_alpha`), настроенный по параметру `click_hp`.
   - Финальный этап ($3\text{ мс}$) сглаживает буфер (`apply_buffer_fadeout`) для предотвращения щелчков в конце.
