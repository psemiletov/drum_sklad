# Документация генератора ковбелла (Cowbell)

Генератор `cowbell_sound` — это модуль синтеза металлической перкуссии в Drumlabooh, смоделированный по принципу классических аналоговых драм-машин (в стиле TR-808 cowbell). Он использует два расстроенных прямоугольных осциллятора (Square Waves), однополюсную фильтрацию НЧ, короткий клик атаки, экспоненциальную огибающую затухания и каскад аналогового перегруза (Drive).

Формат вызова:
```text
cowbell_sound(freq=val1, ratio=val2, decay=val3, tone=val4, drive=val5)
```

## Таблица параметров

| Параметр | Тип | По умолчанию | Диапазон | Описание |
| :--- | :--- | :--- | :--- | :--- |
| **`freq`** | `float` | `560.0` | `200.0` — `1500.0` | Фундаментальная базовая частота первого осциллятора (в Гц). |
| **`ratio`** | `float` | `1.45` | `1.0` — `2.5` | Коэффициент соотношения частоты для второго осциллятора. |
| **`decay`** | `float` | `0.18` | `0.02` — `1.0` | Длительность экспоненциального затухания (в секундах). |
| **`tone`** | `float` | `1200.0` | `400.0` — `8000.0` | Частота среза однополюсного RC-фильтра НЧ (в Гц). |
| **`drive`** | `float` | `1.2` | `0.5` — `5.0` | Коэффициент сатурации/перегруза через функцию `std::tanh`. |

---

## Архитектура и особенности звукообразования

1. **Двухосцилляторный меандр (Square Waves):**
   Металлический дисгармоничный тембр создается суммой двух прямоугольных волн:
   - Осциллятор 1 работает на частоте $f_1 = \text{freq}$ (по умолчанию $560\text{ Гц}$).
   - Осциллятор 2 работает на частоте $f_2 = \text{freq} \cdot \text{ratio}$ (по умолчанию $812\text{ Гц}$ при ratio $1.45$).
   
   Сырые прямоугольные волны ($\pm 1.0$) смешиваются в равной пропорции ($50\% / 50\%$).

2. **Фильтрация тембра и щелчок атаки:**
   - Смешанный сигнал проходит через однополюсный RC-фильтр нижних частот, задаваемый параметром `tone`:
     $$\alpha = \frac{dt}{rc + dt}, \quad rc = \frac{1}{2\pi \cdot \text{tone}}$$
   - В течение первых $1.5\text{ мс}$ ($t < 0.0015\text{ с}$) подмешивается короткий импульсный щелчок для подчеркивания удара палочки.

3. **Огибающая затухания и перегруз:**
   Сигнал умножается на экспоненциальную огибающую спада:
   $$\text{env} = \exp\left(-t \cdot \frac{4.0}{\text{decay}}\right)$$
   Если параметр $\text{drive} > 1.0$, итоговый сигнал насыщается через мягкий клиппинг `std::tanh(\text{sample} \cdot \text{drive})`, после чего применяется финальное сглаживание $3\text{ мс}$ (`apply_buffer_fadeout`).
