# Документация генератора Boom

Генератор `boom` — это универсальный перкуссионный синтезатор с плотным низкочастотным телом, настраиваемой сатурацией, двухступенчатой фильтрацией и опциональным генератором зернистых микро-всплесков (granular micro-bursts). Он отлично подходит для создания глубоких саб-басов, индустриальных ударов, кибернетических томов и глитч-перкуссии.

Формат вызова:
```text
boom(param1=val1, param2=val2, ...)
```

## Таблица параметров

| Параметр | Тип | По умолчанию | Диапазон | Описание |
| :--- | :--- | :--- | :--- | :--- |
| **`duration`** | `float` | `0.35` | `0.05` — `2.0` | Общая длительность звука в секундах. |
| **`freq`** | `float` | `70.0` | `20.0` — `500.0` | Базовая стартовая частота генератора (в Гц). |
| **`sweep`** | `float` | `-40.0` | `-200.0` — `200.0` | Глубина и направление изменения частоты (pitch envelope) во времени. |
| **`noise`** | `float` | `0.3` | `0.0` — `1.0` | Количество шумовой составляющей в теле звука. |
| **`roughness`**| `float` | `0.6` | `0.0` — `1.0` | Интенсивность частотного воббла (шероховатости/расстройки). |
| **`wobble`** | `float` | `24.0` | `0.0` — `100.0` | Скорость (частота в Гц) модуляционного воббла. |
| **`attack`** | `float` | `0.001` | `0.0` — `0.1` | Время атаки огибающей (в секундах). |
| **`release`** | `float` | `0.12` | `0.01` — `2.0` | Время затухания (релиза) огибающей. |
| **`gain`** | `float` | `0.95` | `0.0` — `2.0` | Итоговый уровень выходной громкости. |
| **`bubble`** | `float` | `0.5` | `0.0` — `2.0` | Интенсивность внутренней нелинейной амплитудной модуляции (придает резонансный, упругий характер). |
| **`tone`** | `float` | `1400.0` | `100.0` — `10000.0`| Частота среза выходного низкочастотного фильтра (LPF в Гц). |
| **`granular`** | `bool` | `true` | `0` / `1` | Включение генерации случайных зернистых микро-всплесков. |
| **`grain_mix`**| `float` | `0.4` | `0.0` — `1.0` | Баланс (микс) зернистых микро-всплесков относительно основного сигнала. |

## Архитектура и особенности звучания

1. **Частотный сдвиг и саб-слой:**
   Использует два осциллятора с разной фазой и динамическим изменением высоты тона (`kick_drop`), формируя массивный низкочастотный фундамент.
2. **Фильтрация и сатурация:**
   Сигнал проходит через цепочку фильтров (HPF настроен на 45 Гц для отсечения инфранизкого гула, а LPF настраивается через `tone`), после чего мягко насыщается с помощью `std::tanh` для плотности и компрессии.
3. **Зернистость (`granular`):**
   При активации случайным образом генерирует короткие перкуссионные щелчки и микро-импульсы, добавляя звуку индустриальную фактуру и детализацию.
