# Документация генератора Computer Snare

Генератор `computer_snare` — это синтезатор малого барабана в стиле ранней электроники и минимал-синтеза (Kraftwerk, электро-поп 80-х). Звук формируется сочетанием меандра с кратким падением тона и отфильтрованного псевдослучайного шума.

Формат вызова:
```text
computer_snare(param1=val1, param2=val2, ...)
```

## Таблица параметров

| Параметр | Тип | По умолчанию | Диапазон | Описание |
| :--- | :--- | :--- | :--- | :--- |
| **`freq`** | `float` | `380.0` | `150.0` — `800.0` | Базовая частота тонального тела барабана (в Гц). |
| **`decay`** | `float` | `0.14` | `0.03` — `0.6` | Длительность звучания (в секундах). |
| **`crunch`** | `float` | `0.55` | `0.0` — `1.5` | Уровень громкости шумового слоя (пружины). |
| **`tone`** | `float` | `1100.0` | `200.0` — `8000.0` | Частота среза фильтра нижних частот (LPF в Гц) для шумового слоя. |

---

## Архитектура и особенности звучания

1. **Тональный импульс:**
   Сформирован на основе прямоугольной волны с быстрым экспоненциальным спадом частоты на атаке, создающим плотный прямоугольный «щелчок».
2. **Шумовой слой (Пружина):**
   Генерируется с помощью быстрых битовых сдвигов (Xorshift) и проходит через однополюсный LPF (`tone`), моделируя сухое шуршание подпружины.
3. **Сатурация:**
   Итоговая смесь тона и шума насыщается функциями `std::tanh` с коэффициентом `1.4`, придавая малого барабану необходимую собранность и плотность.
